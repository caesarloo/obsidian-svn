# Obsidian SVN (MVP)

这是一个 Obsidian 1.x 桌面插件，用于在侧边栏中执行 SVN 工作副本的常用操作。

## 当前能力

- 更新工作副本（`svn update`）
- 刷新状态（`svn status`）
- 文件树展示：新增/修改/删除/冲突/未跟踪/缺失
- 文件与文件夹级“暂存/取消暂存”
- 文件还原与文件夹递归还原
- 提交已暂存变更（仅提交暂存集合）
- 生成提交摘要（失败不阻断手动提交）
- 冲突提示与“标记已解决”
- 仓库配置弹窗（路径、可执行文件、用户名、密码）

## 安装与构建

1. 安装依赖

```bash
npm install
```

2. 构建

```bash
npm run build
```

构建后会在 `dist` 目录生成 `main.js`，并自动同步 `manifest.json`、`styles.css` 到 `dist`。

## 使用说明

- 打开命令面板执行：`打开 SVN 面板`
- 或点击左侧 Ribbon 图标 `Open Obsidian SVN`
- 点击 `设置` 配置工作副本路径与凭据
- 在变动文件列表中先“暂存”，再点击“提交变更”

## 说明

- 插件依赖系统已安装且可执行的 `svn` CLI。
- 若关闭“持久化保存密码”，密码仅保存在当前会话内存中。
